Extensión · Productividad

Chats de IA → Vista limpia + PDF

Problema
Guardar una conversación con una IA en PDF arrastra menús, botones y barras laterales.
Idea
Una vista limpia de la conversación, lista para imprimir o guardar.
Plan
Funciona con ChatGPT, Claude, Gemini, Copilot y otras IAs; recorre el chat completo y conserva código, tablas y fórmulas.
Hecho
Publicada en la Chrome Web Store. Gratuita, sin recogida de datos.

Extensión · Redes sociales

Solo Siguiendo para X

Problema
El inicio de X mezcla lo que sigues con lo que decide el algoritmo.
Idea
Ver solo lo que publican las cuentas que has elegido seguir.
Plan
Abre siempre «Siguiendo» y oculta «Para ti», anuncios y sugerencias; los reposts, si quieres.
Hecho
Enviada a la Chrome Web Store; mientras tanto, se puede instalar desde GitHub.
